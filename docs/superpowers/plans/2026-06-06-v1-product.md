# Windows Rogue Software Cleaner v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个可用的 Windows 桌面“流氓软件清理”成品：完整扫描→用户确认→可恢复清理→清理后验证→结果报告与隔离区还原。

**Architecture:** WPF + MVVM。扫描/清理/验证/报告/隔离区分层（Core/Windows/UI/Data/Utils）。所有清理动作都必须：用户显式确认、全量日志、尽量可恢复（优先禁用与隔离），并输出可审计报告。

**Tech Stack:** C#、WPF（net8.0-windows）、Windows Registry / ServiceController / schtasks.exe（参数严格校验）、System.Text.Json。

## Scope Locked for v1 (“成品”)

### Scanning Sources
- 计划任务（只读）
- 系统服务（只读）
- 已安装程序列表（只读）
- 可选：桌面快捷方式、AppData/Program Files/Temp（目录扫描需限速/取消/白名单，避免误报与性能问题）

### Cleaning Actions (Recoverable First)
- 进程：停止（Stop）为主，避免直接删除文件
- 启动项：禁用/还原（已具备）
- 计划任务：禁用/启用（不删除）
- 系统服务：禁用/启用（不删除）
- 文件：移动到隔离区（不直接删除），并记录哈希/大小/原路径

### Verification
- 进程是否停止
- 启动项是否禁用
- 计划任务是否禁用
- 服务是否禁用
- 文件是否在隔离区

### Report & Audit
- 扫描报告（JSON）
- 清理执行报告（JSON，已具备基础）
- 验证报告（JSON）
- 可选：汇总 HTML 报告（纯本地）

### UI
- “类似任务管理器”：顶部 Tab（进程/启动项/服务/计划任务/安装程序/隔离区/报告）
- 每个 Tab：列表 + 详情（证据/原因/建议）+ 勾选 + 进入确认/执行

### Privilege Strategy
- 默认以普通权限启动；首次进入“系统级清理”时弹出说明并提供“以管理员重启（记住选择）”。
- 若用户在设置里选择“启动即管理员”，则下次启动时自动提示 UAC（通过自重启提权实现，而不是强制 manifest requireAdministrator）。

### Task 2: Add Read-Only Service Scanning

**Files:**
- Create: `d:/delete_app/src/DeleteApp/Windows/ServiceReader/ServiceScanner.cs`

- [ ] **Step 1: Implement scanner using ServiceController**

```csharp
using System.ServiceProcess;
using DeleteApp.Core.Scanner;
using DeleteApp.Data.Models;
using DeleteApp.Utils.Logger;

namespace DeleteApp.Windows.ServiceReader;

public sealed class ServiceScanner : IScanner
{
    private readonly ILocalLogger _logger;

    public ServiceScanner(ILocalLogger logger) => _logger = logger;

    public string Name => "Service";

    public Task<IReadOnlyList<ScanCandidate>> ScanAsync(CancellationToken cancellationToken)
    {
        var items = new List<ScanCandidate>();

        foreach (var svc in ServiceController.GetServices())
        {
            cancellationToken.ThrowIfCancellationRequested();
            try
            {
                items.Add(new ScanCandidate(
                    Guid.NewGuid(),
                    ScanSource.Service,
                    svc.ServiceName,
                    null,
                    null,
                    null,
                    UniqueKey: svc.ServiceName));
            }
            catch (Exception ex)
            {
                _logger.Warn($"Service scan item failed: {ex.GetType().Name}");
            }
            finally
            {
                svc.Dispose();
            }
        }

        return Task.FromResult<IReadOnlyList<ScanCandidate>>(items);
    }
}
```
